# SullyOS Memory Hub 快速操作

## 本地打开

1. 双击 `start-memory-hub.bat`。
2. 浏览器打开 `http://localhost:8787`。
3. 第一页点 `开始连接`。

## 最简单用法

### 方式 A：从 SullyOS 读取

1. 点右上角齿轮。
2. 填 `SullyOS 地址`，本机通常是 `http://localhost:5173`。
3. `导出端点` 先保持 `/memory-palace/export.json`。这个端点应该返回 SullyOS 的全局记忆宫殿，不是单个角色页面。
4. 点 `保存`。
5. 回到 `开始连接`，点 `从 SullyOS 读取`。

如果提示无法读取，说明 SullyOS 还没有开启这个只读导出端点。先用方式 B。

### 方式 B：导入 JSON

1. 在 SullyOS 记忆宫殿里导出全局 JSON。
2. Memory Hub 点 `导入 JSON`。
3. 选那个导出的 JSON 文件。

## 读进来以后看哪里

- `AI / 角色`：看全局记忆宫殿里的角色索引，点角色只是筛选数据。
- `记忆房间`：按客厅、卧室、书房、用户房间、自我房间等查看全局宫殿里的记忆。
- `门牌 / 地标`：看稳定事实、核心身份、关系定位。
- `印象档案`：看 SullyOS 导出的角色印象和 learned 印象。
- `Feel 情绪沉淀`：看情绪标签和沉淀。
- `搜索`：按关键词搜记忆。
- `向量管理`：看哪些记忆有向量，哪些缺向量。
- `健康检查`：确认角色、记忆、门牌、印象、向量数量是否正常。
- `同步与备份`：导出 Hub 备份，或手动同步到 Ombre。

## 安全边界

当前版本不会写回 SullyOS。同步到 Ombre 也需要手动点。
